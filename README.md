# Multi-Vendor E-Commerce Platform

A production-ready Multi-Vendor E-Commerce Platform where multiple vendors can register, manage their stores, upload products, receive orders, and sell products through a single marketplace.

## Project Structure

- `frontend/`: React application containing the user interfaces for Admin, Vendor, and Customer panels.
- `backend/`: Laravel backend handling the core business logic, APIs, and database.
- `docs/`: Technical documentation and API specifications.

## Technology Stack

### Frontend
- **Framework:** React
- **Language:** JavaScript
- **Styling:** Bootstrap
- **Networking:** Axios
- **Routing:** React Router
- **State Management:** Context API
- **Forms:** React Hook Form
- **Notifications:** React Toastify
- **Charts:** Recharts

### Backend
- **Framework:** Laravel 12
- **Language:** PHP 8.4
- **Authentication:** Laravel Sanctum
- **Roles & Permissions:** Spatie Permission
- **Database:** MySQL
- **Storage:** Cloudinary
- **Payments:** Razorpay

## Setup Requirements
To run this project locally, ensure you have the following installed:
- Node.js & npm (v20+)
- PHP (v8.4+)
- Composer
- MySQL Database
- Git
